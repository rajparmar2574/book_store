# Book Store Website

A responsive and user-friendly online Book Store website developed using HTML, CSS, JavaScript, PHP, and MySQL. The platform allows users to browse books, view book details, and purchase books through an intuitive interface.

## Overview

This project is an online bookstore designed to provide users with an easy way to explore and purchase books. It includes user authentication, book management, shopping cart functionality, and an admin panel for managing the store.

## Features

- Browse available books
- Search books by title or category
- View detailed book information
- Add books to cart
- User registration and login
- Order management
- Responsive design
- Admin panel for managing books, users, and orders

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- PHP
